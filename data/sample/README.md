# 선별 정확도 표본 (PLAN 작업 16 · 성공 기준 SC-3)

**목표:** 담당자가 직접 고른 필지 **50건 중 90% 이상(45건 이상)**이 도구의 후보 목록에 들어오는지 확인합니다.

이 표본은 **담당자의 판단이 기준**이라서 개발자(또는 AI)가 대신 만들 수 없어요. 도구가 맞게 골랐는지를 담당자의 눈으로 확인하는 거예요.

---

## 1. 표본 고르기

선별 조건(면적 1,000㎡ 이상 · 지목 대 · 용도지역 일반상업·준주거·제3종일반주거)을 **직접 확인해서** "이건 후보가 맞다"고 판단한 필지 50건을 고르세요.

- 영등포구·도봉구에서 고르세요. 두 구를 섞어도 됩니다.
- 도구가 보여 준 결과에서 골라 적으면 **측정이 아니라 자기 확인**이 되어 의미가 없어요. 토지이음 등 **별도로 직접 확인**한 필지를 권해요.
- 일부러 경계에 가까운 필지(면적 1,000~1,100㎡, 두 용도지역에 걸친 필지)도 몇 건 넣으면 더 잘 점검돼요.

## 2. 파일 만들기

1. `data/sample/template.csv`를 복사해서 **`data/sample/sample.csv`**로 저장합니다.
2. 엑셀로 열어 아래처럼 한 줄에 한 필지씩 적습니다. (엑셀에서 "CSV로 저장"하면 돼요. 한글 인코딩은 알아서 맞춰 읽어요.)

| 구 | 동 | 지번 |
|---|---|---|
| 영등포구 | 여의도동 | 50 |
| 도봉구 | 창동 | 347 |
| 영등포구 | 영등포동1가 | 7-2 |
| 도봉구 | 방학동 | 산 89-2 |

위 4줄은 **형식을 보여 주는 예시일 뿐**이에요. 실제 표본이 아니니 그대로 넣지 마세요.

- 열 이름은 `구, 동, 지번`입니다. (`주소` 한 칸에 "서울특별시 영등포구 여의도동 50"처럼 적어도 읽어요.)
- 산 지번은 `산 89-2`처럼 앞에 "산"을 붙입니다.
- 동 이름은 `영등포동1가`처럼 데이터와 같게 적어야 찾을 수 있어요.
- 같은 필지를 두 번 적으면 한 건으로 세요.

## 3. 측정하기

my-app 폴더에서 아래 명령을 실행합니다. (AI를 쓰지 않아서 비용이 들지 않아요.)

```bash
npm run eval:sample
```

화면에 다음이 나옵니다.

- 표본 중 후보에 들어온 비율 (목표 90% 이상 → ✅/❌)
- 후보에 못 들어온 필지와 **그 이유** (면적 부족·지목·용도지역, 값이 비어 있음, 데이터에 없음)

결과는 `evals/results/sample-accuracy.md`에도 저장돼요.

## 4. 결과 읽는 법

| 표시 | 뜻 | 할 일 |
|---|---|---|
| ✅ 후보 포함 | 도구가 담당자와 같게 골랐어요 | 없음 |
| ❌ 제외 (면적 980㎡ …) | 도구는 조건에 안 맞다고 봤어요 | 데이터가 틀렸는지, 담당자 기준이 다른지 확인 |
| ⚠️ 확인 필요 | 원본에 지목·면적·용도지역이 비어 있어요 | 후보로 세지 않아요 (별도 집계) |
| ❓ 못 찾음 | 동·지번을 데이터에서 못 찾았어요 | 오타인지 확인. 영등포구·도봉구가 맞는지도 확인 |

"제외"가 나온 필지는 **도구가 틀린 건지, 데이터가 오래된 건지(기준일 2026-05-13), 담당자 기준이 다른 건지** 함께 보고 결정해요. 두 번째 용도지역에만 해당하는 필지는 설계상 주된 용도지역으로만 판정해서 제외돼요(PRD 5번).
