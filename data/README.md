## 1. 원본 내려받기 (PLAN 작업 1)

> 2026-11-12에 확인한 내용입니다. 사이트 화면은 바뀔 수 있어요. 토지특성정보는 반년마다 갱신되니, 새 자료가 나오면 같은 방법으로 다시 받으면 됩니다.

1. 브이월드(디지털트윈국토)에 로그인합니다. (회원가입·로그인은 직접 해 주세요)
2. [공간정보 다운로드 → "토지특성정보"](https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?dsId=4&svcCde=NA&searchKeyword=%ED%86%A0%EC%A7%80%ED%8A%B9%EC%84%B1%EC%A0%95%EB%B3%B4) 페이지를 엽니다.
3. 검색 조건을 고릅니다.
   - 시·도: **서울특별시**
   - 시·군·구: **영등포구** (도봉구도 같은 방법으로 한 번 더)
   - 구분: **전체데이터**
   - 파일포맷유형: **SHP**
4. **조회**를 누르고, 기준일이 **가장 최근**인 "토지특성공간정보" 행의 **다운로드**를 누릅니다.
5. 받은 압축 파일(`AL_D194_<구코드>_<날짜>.zip`)을 풉니다. 안에 `.shp .shx .dbf .prj .cpg` 파일이 있어요.
6. 그중 **`.dbf` 파일만** `data/raw/`에 넣습니다. (지목·면적·용도지역 같은 속성값이 모두 이 파일에 들어 있어요)

**참고**
- 구 코드: 영등포구 `11560`, 도봉구 `11320`
- 열 이름이 A0~A26 코드로 되어 있어요. 뜻은 같은 페이지의 **"컬럼 정의서 다운로드"**에서 확인할 수 있어요. 앱에서 쓰는 열은 DESIGN.md 3.1 대응표에 정리되어 있어요.
- `.cpg` 파일에는 UTF-8이라고 적혀 있지만 실제 한글은 **EUC-KR**이에요. 스크립트가 알아서 맞게 읽어요.
- 서울 전체 CSV(시·군·구 "전체" + CSV)로 받아도 확인 스크립트는 읽을 수 있어요.

## 2. 열 이름 확인하기

my-app 폴더에서 아래 명령을 실행합니다. (10초 정도 걸려요)

```bash
npm run inspect:raw
```

화면에 다음이 나옵니다.

- 인코딩 (EUC-KR이면 한글 변환이 필요하다고 알려 줌)
- 전체 행 수, **영등포구·도봉구 건수**, 데이터 기준일
- 열 목록과 첫 행 예시 값 (A코드 열은 추정한 뜻도 함께)
- DESIGN.md 3.1 대응표와 비교 결과 (✅ / ❌ + 비슷한 열)
- 두 구에서 지목·면적·용도지역이 비어 있는 건수 ("확인 필요" 예상 규모)
- 개인정보로 의심되는 열
